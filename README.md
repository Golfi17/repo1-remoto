# Etapas del Desarrollo de Software

## 1. Análisis de requisitos

Es la fase donde se decide qué debe hacer el programa.

![Análisis de requisitos](https://images.unsplash.com/photo-1521737604893-d14cc237f11d)

### Requisitos funcionales

Son las funciones que debe tener el software.

Ejemplo: iniciar sesión o guardar datos.

![Requisitos funcionales](https://images.unsplash.com/photo-1552664730-d307ca884978)

### Requisitos no funcionales

Son características de calidad del sistema.

Ejemplo: seguridad o velocidad.

![Requisitos no funcionales](https://images.unsplash.com/photo-1516321318423-f06f85e504b3)

---

## 2. Diseño

Se planifica cómo será el programa antes de programarlo.

![Diseño software](https://images.unsplash.com/photo-1515879218367-8466d910aaa4)

---

## 3. Codificación y compilación

Es la parte donde se escribe el código y se convierte en ejecutable.

![Codificación](https://images.unsplash.com/photo-1518770660439-4636190af475)

---

## 4. Pruebas

Sirven para comprobar que el programa funciona bien.

![Pruebas software](https://images.unsplash.com/photo-1516321165247-4aa89a48be28)

### Pruebas unitarias

Revisan partes pequeñas del programa.

![Pruebas unitarias](https://images.unsplash.com/photo-1516116216624-53e697fedbea)

### Pruebas de integración

Comprueban que todos los módulos funcionen juntos.

![Pruebas integración](https://images.unsplash.com/photo-1551434678-e076c223a692)

---

## 5. Explotación

Es cuando el programa ya se usa en la vida real.

![Explotación](https://images.unsplash.com/photo-1496171367470-9ed9a91ea931)

---

## 6. Mantenimiento

Consiste en corregir errores o mejorar el software.

![Mantenimiento](https://images.unsplash.com/photo-1519389950473-47ba0277781c)

---

## 7. Documentación

Son los documentos que explican el programa y su funcionamiento.

### Tipos de documentos

- Manual de usuario
- Documentación técnica
- Informes de pruebas

![Documentación](https://images.unsplash.com/photo-1455390582262-044cdead277a)
